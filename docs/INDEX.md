## 今後フォルダが増えた場合の書き方

新しいドキュメントフォルダ（例: `docs/guide/` や `docs/design/` など）を追加したら、
上の表に1行追加する。「このフォルダに行けば何がわかるか」が一目で分かる粒度で書くこと。
